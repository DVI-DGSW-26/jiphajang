# 집하장

> 흩어진 데이터를 한 지붕 아래로 — 물류팀 업무 보고 서비스

거래처·품목·창고·차량 같은 **기본 데이터**를 한곳에 모으고, **입고·출고·배차·재고 보고서**가 그 데이터를 끌어다 써요.
보고서는 엑셀과 PDF(A4 가로, 결재란 포함)로 내려받아요.

## 디자인 원칙

1. 한 번 입력하면 어디서나 끌어온다
2. 자동과 직접 입력은 눈으로 구분된다
3. 한 화면에 주 버튼은 하나
4. 출력물은 종이 기준
