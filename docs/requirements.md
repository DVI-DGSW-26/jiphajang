# 요구사항 정리

매뉴얼 이후 확인한 내용이에요. 정해지는 대로 이 문서를 고쳐요.

## 확정

- **범위**: [`scope-schedule.md`](scope-schedule.md)가 기준이에요. 매뉴얼의 입고·출고·배차·재고 보고서는 예시이고, 배차는 만들지 않아요.
- **보고 흐름**: 지금은 엑셀 파일을 전달하는 것으로 끝나요. 앱 안에서 결재하는 흐름은 없어요.
- **로그인 필요**. 역할은 둘이에요.
  - 보고자: 보고서와 기본 데이터를 쓰고 고칠 수 있어요
  - 열람자: 내려받기만 할 수 있어요
- **재고**: 지금은 인보이스 엑셀 파일의 입고·출고 값을 엑셀 함수로 더하고 빼서 구해요. 앱에서도 입고·출고 기록으로 계산하는 방식이 기준이에요.
- **서버**: 사내에 둬요. 원하는 기술 스택은 따로 없어요.
- **역할 나눔**: 서버(API·DB)는 서버 담당이 따로 만들어요. 이 저장소는 화면(프런트엔드)만 만들어요.
- **배포**: 서버가 화면까지 같이 내보내요. 화면은 `npm run build` 결과(`dist/`)만 넘기고, 화면과 API가 같은 주소를 써요(API는 `/api` 아래). 파일이 없는 주소(`/auth/callback` 등)는 `index.html`로 돌려줘요. 외부 클라우드(Vercel 등)에는 올리지 않아요. 서버 담당용 안내는 [`deploy.md`](deploy.md).

## 매뉴얼의 예시 값

매뉴얼에 나온 품목(A-100 등), 표 열, 문서번호 형식(`OUT-20261007-01`)은 **이해를 돕기 위한 예시**예요. 실제 항목이 아니에요.
