# 집하장 디자인 매뉴얼 — 개발용 요약

원본: [`design-manual.pdf`](design-manual.pdf) (버전 2 · 2026년 10월). 값이 서로 다르면 PDF가 기준이에요.

PDF는 [`design-manual/index.html`](design-manual/index.html)에서 뽑아요. 매뉴얼을 고칠 때는 HTML을 고치고 `npm run manual:pdf`로 PDF를 다시 만들어요(Chrome이나 Edge 필요). 색·글자 토큰은 앱과 같은 `src/styles/tokens.css`를 불러 써요.

## 버전 2에서 바뀐 것

- 서비스 설명을 [개발 범위](scope-schedule.md)에 맞춤: Invoice → 마스터·출하 원장 → 결과 6종. 배차·차량·입고/출고 보고서 예시를 뺐어요.
- 원칙 2를 “값이 어디서 왔는지 눈으로 구분된다”로 넓히고, 출처 네 가지(판독·계산·마스터·직접 입력)를 새 장(8장)으로 정리했어요. Invoice 올리기와 판독 결과 확인 화면도 넣었어요.
- 상단 바 메뉴, 배지(미수·확인 필요·선적중, 한국/현지 출하), 표·확인창·빈 화면 예시를 출하 업무로 바꿨어요.
- 숫자 형식(단가 소수 4자리, USD 2자리, 환율 2자리, KRW 정수)과 날짜 형식을 정했어요.
- 출력물: 문서번호(`IN`/`OUT`/`DSP`/`STK`) 대신 `결과 이름_기준일` 파일 이름. 결재란은 아직 미정이라 “넣으면 이 자리”로만 남겼어요.
- 부품 파일 `components/bundle.css` 대신 `src/styles/tokens.css`, 함께 드리는 파일 목록을 실제 `assets/logo/`에 맞췄어요.
- label 설명의 “않습니다”를 해요체로 고쳤어요.

## 1. 디자인 원칙 (판단이 애매할 때 이 순서로)

1. **한 번 입력하면 어디서나 끌어온다** — 같은 값을 두 번 치게 하지 않아요. Invoice에 있는 값은 읽어서 채우고, 마스터에 있는 값은 고르기만 하면 채워져요.
2. **값이 어디서 왔는지 눈으로 구분된다** — 판독·계산·마스터에서 온 칸은 `paper-warm` 바탕 + 출처 표시, 직접 친 칸은 흰 바탕.
3. **한 화면에 주 버튼은 하나** — `ink` 주 버튼 하나, 나머지는 보조 버튼.
4. **출력물은 종이 기준** — 엑셀·PDF는 흑백 인쇄로도 다 읽혀야 하고, 제목·기준일은 늘 같은 자리.

## 2. 로고

- 흰 바탕용 `jiphajang-logo`, 진한 바탕용 `jiphajang-logo-reverse`, 진회색 바탕까지 들어간 `jiphajang-logo-reverse-on-dark` (`assets/logo/`)
- 로고 둘레에 지붕 높이만큼 여백. 글자 높이 16px(인쇄 5mm)보다 작으면 앱 아이콘 사용.
- 앱 아이콘: ‘ㅈ’ 겸 지붕, 지붕은 `vest`, 모서리는 한 변의 23%. SVG, PNG 512·1024px.
- 금지: 흰 바탕에 형광 지붕, 늘이기/줄이기, 그림자·효과, 기울이기.

## 6. 화면 부품 (클래스 접두사 `jh-`, 토큰은 `src/styles/tokens.css`)

- **버튼**: 주 버튼은 `ink` 바탕 + `vest` 글자, 한 화면에 하나. 높이 PC 36px / 휴대폰 44px. 삭제는 확인창으로 한 번 물어요. 로딩 상태 “저장 중…”.
- **입력칸**: 라벨은 항상 위. 마스터 값은 `코드 · 이름`. 자동으로 채운 칸에는 출처 표시. 오류 문구는 칸 아래.
- **배지**: 상태(정상·수금 / 부족·미수·확인 필요 / 선적중 / 예시), 진한 배지는 종류 구분(한국 출하·현지 출하)에만.
- **알림(토스트)**: 화면 아래 가운데, 2~4초, 한 번에 하나, 사과 문구 없음.
- **상단 바**: `ink`를 넓게 쓰는 유일한 곳. 현재 메뉴에 `vest` 밑줄. 메뉴: Invoice / 출하 원장 / 결과 / 재고·선적 / 마스터. 결과 아래에 수출신고취합, 현지 Invoice List, 수금현황, U71X Offset, 재고·출하 현황. 오른쪽에 “저장됨 14:32”.
- **표**: 자동 칸은 미색 배경 + 머리줄에 출처 표시. 숫자 오른쪽 정렬, 합계줄 위 진한 선. 확인이 필요한 행은 `alert-soft`.
- **확인창**: 왼쪽은 항상 “닫기”. 되돌릴 수 없는 일에만.
- **빈 화면**: 지금 상황 + 다음 행동(예: “+ Invoice 올리기”, “엑셀에서 가져오기”).

## 7. 값의 출처와 Invoice 판독

| 출처 | 보이는 방식 | 예 |
|---|---|---|
| 판독 (Invoice에서 읽음) | `paper-warm` + “판독” | Invoice No., 날짜, Part Number, 수량, 단가, Box QTY |
| 계산 | `paper-warm` + “계산” | Total QTY = Set QTY × Box QTY, 금액 = 단가 × 수량, 금액(KRW) = 금액(USD) × 환율, Due Date |
| 마스터 | `paper-warm` + “마스터” | Set QTY, 고객사·회사명, 인도조건, Ship to, 결제조건 |
| 직접 입력 | 흰 칸, 비어 있으면 “입력해 주세요” | 수출신고번호, BL No., Container No., 수리일자, 선적일자, 환율, ETD / ETA / ATA, 실제 수금일 |

- Invoice는 끌어다 놓거나 골라서 올려요(엑셀, 여러 개 한 번에).
- 원장에 넣기 전에 판독 결과를 한 화면에서 보여줘요. Invoice 값이 마스터와 다르면 **Invoice 값을 쓰고** “확인 필요”로 표시해요.
- 못 읽은 칸은 어디를 고치면 되는지 함께 써요.
- 자동 값을 손으로 고칠 수 있는지, 고친 값을 어떻게 표시할지는 미정이에요.

## 8. 상태 · 숫자 · 레이아웃

| 상태 | 보이는 방식 |
|---|---|
| hover | 테두리 grey-300, 주 버튼 `ink-strong`, 표 행 grey-100 |
| active | 보조 버튼 바탕 grey-100, 주 버튼 98% 축소 |
| focus | 흰 바탕은 `ink` 2px, 진한 바탕은 `vest` 2px 테두리. 지우지 않아요 |
| disabled | 글자 `text-disabled`, 바탕 grey-50 |

| 상태 배지 | 색 | 쓰는 곳 |
|---|---|---|
| 정상 | `vest-soft` + `text-primary` | 정상, 수금, 도착, 읽음 |
| 미수 | `alert-soft` + `alert` | 부족, 미수, 오류, 확인 필요 |
| 선적중 | grey-100 + `text-secondary` | 선적중, 도착 예정, 진행 중 |
| 예시 | 흰 바탕 + `line` 테두리 + `text-tertiary` | 예시, 참고, 마스터 |

| 값 | 형식 | 예 |
|---|---|---|
| 수량 (Set·Box·Total QTY, 재고) | 정수, 천 단위 쉼표 | `60,000` |
| 단가 (USD) | 소수 4자리 | `0.5120` |
| 금액 (USD) | 소수 2자리, 천 단위 쉼표 | `30,720.00` |
| 환율 | 소수 2자리 | `1,385.50` |
| 금액 (KRW) | 정수, 천 단위 쉼표 | `42,562,560` |
| 날짜 | `YYYY-MM-DD`, 좁으면 `MM-DD` | `2026-10-07` |
| Invoice No.·품번·BL No. | 받은 그대로, 왼쪽 정렬 | `MC261005A` |

- 통화는 칸마다 붙이지 않고 머리줄에 `Amount (USD)`처럼 한 번만.
- 음수 재고는 `alert` 글자에 앞에 −.
- 아이콘: 선 아이콘만, 두께 1.75px, 둥근 끝, 24px 격자. 색 `text-primary`/`text-tertiary`, 진한 바탕에서만 `vest`. 아이콘 버튼엔 `aria-label`. 이모지 금지.
- 레이아웃: 최대 폭 1320px, 좌우 여백 `space-3` 16px, 묶음 사이 `space-4` 24px, 큰 구역 사이 `space-5` 40px, 모서리 4·6·12px.
- 휴대폰 폭에서 가로 스크롤 없음. 넓은 표만 표 안에서 스크롤하고, 머리줄과 첫 열을 고정해요.
- 다크 모드 없음. 사무실 PC 중심.

## 9. 출력물 (엑셀 · PDF)

- 흰 바탕에 진회색·회색만. 형광 연두 없음.
- 용지 A4 가로(297×210mm). 첫 장 13줄, 다음 장부터 19줄. 머리줄은 장마다 다시 찍어요.
- 왼쪽 위: 흰 바탕용 로고, 출하 구분과 결과 이름, 기준일·작성자.
- 오른쪽 위: 결재란(담당 · 팀장 · 센터장)은 **미정**. 넣으면 이 자리에, 도장이 들어가게 칸 높이 넉넉히.
- 파일 이름: `결과 이름_기준일` — 예: `현지 출하 Invoice List_20261007.xlsx`
- 엑셀: 머리줄 고정, 자동 필터, 합계는 표 맨 아래. 숫자는 숫자 서식으로 넣어요.
- 맨 아래: 출력 시각과 쪽 번호(`1 / 3`).
