# 집하장 디자인 매뉴얼 — 개발용 요약

원본: [`design-manual.pdf`](design-manual.pdf) (버전 1 · 2026년 10월). 값이 서로 다르면 PDF가 기준이에요.

> 보고서 종류(입고·출고·배차·재고)와 문서번호 종류는 매뉴얼의 예시예요. 실제 화면과 결과물은 [`scope-schedule.md`](scope-schedule.md)를 따르고, **배차는 범위에 없어요**. 색·글꼴·부품 규칙은 그대로 적용해요.

## 1. 디자인 원칙 (판단이 애매할 때 이 순서로)

1. **한 번 입력하면 어디서나 끌어온다** — 같은 값을 두 번 치게 하지 않아요. 기본 데이터에 있는 값은 고르기만 하면 채워져요.
2. **자동과 직접 입력은 눈으로 구분된다** — 기본 데이터에서 온 칸은 `paper-warm` 바탕 + “자동” 표시, 직접 친 칸은 흰 바탕.
3. **한 화면에 주 버튼은 하나** — `ink` 주 버튼 하나, 나머지는 보조 버튼.
4. **출력물은 종이 기준** — 엑셀·PDF는 흑백 인쇄로도 다 읽혀야 하고, 결재란·문서번호는 늘 같은 자리.

## 2. 로고

- 흰 바탕용 `jiphajang-logo`, 진한 바탕용 `jiphajang-logo-reverse` (`assets/logo/`)
- 로고 둘레에 지붕 높이만큼 여백. 글자 높이 16px(인쇄 5mm)보다 작으면 앱 아이콘 사용.
- 앱 아이콘: ‘ㅈ’ 겸 지붕, 지붕은 `vest`, 모서리는 한 변의 23%.
- 금지: 흰 바탕에 형광 지붕, 늘이기/줄이기, 그림자·효과, 기울이기.

## 3. 색 — 흰색 90 · 진회색 8 · 형광 2

| 토큰 | 값 | 용도 |
|---|---|---|
| `paper` | `#FFFFFF` | 기본 바탕 |
| `ink` | `#3A3633` | 브랜드 진회색 |
| `vest` | `#C9DD3C` | 형광 포인트 (**진회색 위에서만**, 대비 7.9:1 / 흰 바탕 위 1.5:1 금지) |
| `alert` | `#A8432F` | 오류 |
| `paper-warm` | `#FAF9F6` | 보조 바탕 · 자동 칸 |
| `line` | `#E6E2D8` | 구분선 |
| `ink-strong` | `#2A2724` | 주 버튼 hover |
| `vest-soft` | `#EEF5C4` | “정상” 배지 바탕 |
| `alert-soft` | `#F6E6E1` | “부족/오류” 배지 바탕 |

- 쨍한 빨강·파랑·노랑·주황은 넓은 면에 쓰지 않아요(정당 색 회피).
- 상태는 색만으로 구분하지 않고 글자(“정상”, “부족”)를 함께 써요.

### 따뜻한 회색 11단계 (흰 바탕 대비)

| 0 | 50 | 100 | 200 | 300 | 400 | 500 | 600 | 700 | 800 | 900 |
|---|---|---|---|---|---|---|---|---|---|---|
| `#FFFFFF` | `#FAF9F6` | `#F3F1EC` | `#E6E2D8` | `#D2CDC2` | `#B3ADA3` | `#8F8981` | `#77706A` | `#5A544F` | `#3A3633` | `#2A2724` |
| 1.0 | 1.1 | 1.1 | 1.3 | 1.6 | 2.2 | 3.5 | 4.9 | 7.5 | 12.0 | 14.9 |

글자로 쓸 수 있는 가장 연한 회색은 600. 500 이하는 아이콘·자리표시·비활성에만. **화면에서는 단계 대신 역할 토큰을 써요.**

| 역할 토큰 | 회색 | 용도 |
|---|---|---|
| `paper` | grey-0 | 기본 바탕 |
| `paper-warm` | grey-50 | 보조 바탕 · 자동 칸 |
| `line` | grey-200 | 구분선 |
| `text-primary` | grey-800 | 제목·본문 |
| `text-secondary` | grey-700 | 설명 · 자동 칸 글자 |
| `text-tertiary` | grey-600 | 라벨·날짜·도움말 |

## 6. 화면 부품 (클래스 접두사 `jh-`, `components/bundle.css`)

- **버튼**: 주 버튼은 `ink` 바탕 + `vest` 글자, 한 화면에 하나. 높이 PC 36px / 휴대폰 44px. 삭제는 확인창으로 한 번 물어요. 로딩 상태 “저장 중…”.
- **입력칸**: 라벨은 항상 위. 기본 데이터 값은 `코드 · 이름` (예: `A-100 · 박스 대`). 오류 문구는 칸 아래.
- **배지**: 정상 / 부족 / 예시, 보고서 종류(입고·출고·배차·재고).
- **알림(토스트)**: 화면 아래 가운데, 2~4초, 한 번에 하나, 사과 문구 없음.
- **상단 바**: `ink`를 넓게 쓰는 유일한 곳. 현재 메뉴에 `vest` 밑줄. 메뉴: 업무 보고 / 기본 데이터. 오른쪽에 “저장됨 14:32”.
- **표**: 자동 칸은 미색 배경 + 머리줄 “자동” 표시. 숫자 오른쪽 정렬, 합계줄 위 진한 선. 부족 행은 강조.
- **확인창**: 왼쪽은 항상 “닫기”. 되돌릴 수 없는 일에만.
- **빈 화면**: 지금 상황 + 다음 행동(예: “+ 품목 추가”, “엑셀에서 가져오기”).

## 7. 상태 · 아이콘 · 레이아웃

| 상태 | 보이는 방식 |
|---|---|
| hover | 테두리 grey-300, 주 버튼 `ink-strong`, 표 행 grey-100 |
| active | 보조 버튼 바탕 grey-100, 주 버튼 98% 축소 |
| focus | 흰 바탕은 `ink` 2px, 진한 바탕은 `vest` 2px 테두리. 지우지 않아요 |
| disabled | 글자 `text-disabled`, 바탕 grey-50 |

- 상태 표시: 정상 = `vest-soft` + `text-primary` / 부족·오류 = `alert-soft` + `alert` / 예시 = 흰 바탕 + `line` 테두리 + `text-tertiary`
- 아이콘: 선 아이콘만, 두께 1.75px, 둥근 끝, 24px 격자. 색 `text-primary`/`text-tertiary`, 진한 바탕에서만 `vest`. 아이콘 버튼엔 `aria-label`. 이모지 금지.
- 레이아웃: 최대 폭 1320px, 좌우 여백 `space-3` 16px, 묶음 사이 `space-4` 24px, 큰 구역 사이 `space-5` 40px, 모서리 4·6·12px.
- 휴대폰 폭에서 가로 스크롤 없음. 넓은 표만 표 안에서 스크롤.
- 다크 모드 없음. 사무실 PC 중심.

## 8. 출력물 (엑셀 · PDF)

- 흰 바탕에 진회색·회색만. 형광 연두 없음.
- 용지 A4 가로(297×210mm). 첫 장 13줄, 다음 장부터 19줄.
- 왼쪽 위: 흰 바탕용 로고, 보고서 종류와 제목, 문서번호·보고일자·작성자.
- 오른쪽 위: 결재란(담당 · 팀장 · 센터장), 도장이 들어가게 칸 높이 넉넉히.
- 문서번호: `종류-날짜-순번` — `IN`(입고) `OUT`(출고) `DSP`(배차) `STK`(재고). 예: `OUT-20261007-01`
- 맨 아래: 출력 시각과 쪽 번호(`1 / 3`).
- 출고 보고 열 예시: No · 납품처 · 납품주소 · 품목코드 · 품목명 · 수량 · 차량번호 · 기사, 마지막에 계.
